## PLO with two boards, half the pot to each

Each board is a separate [Omaha-rule](/glossary#omaha-rule) hand (2 hole + 3 board). [Double board](/glossary#double-board), usually run as a [bomb pot](/glossary#bomb-pot). **Rarity: moderate.**

## Cheat sheet

- Four hole cards, [pot-limit](/glossary#pot-limit), 8-max (WSOP).
- Two flops, turns and rivers; second board gets no extra burn.
- Best hand on each board takes half. Win one outright, tie the other: 75/25. Ties inside a board are [quartered](/glossary#quartered) when two players split a half.
- Different hole-card pairs allowed per board. No mixing boards.
- Odd chip: unspecified by WSOP; TDA default is first seat left of the button.

## Watch out for

- Whether the room splits by board (common live rule) or the single best hand wins all (Wikipedia mentions it as an option).
- Equity is the average of both boards: 55/55 beats 90/10 once quartering is in play.
- One-board nuts with no backup equity.
- WSOP base game has blinds and pre-flop betting; most live use is ante-only.
